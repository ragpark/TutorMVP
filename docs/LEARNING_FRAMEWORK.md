# Learning Framework

Learning Objectives are the central planning, assessment, recommendation, and tutoring unit. Concepts explain what each LO requires. `DEPENDS_ON` edges encode prerequisites. Assessment responses provide evidence, and the deterministic mastery model maps scores to `MASTERED`, `PARTIAL`, `PRACTICING`, or `NEEDS_REVIEW`.

Thresholds: score `>= .85` increases mastery significantly; `.60-.85` produces partial mastery; `< .60` signals practice/review need. Low prerequisite mastery below `.70` triggers remediation recommendations.
